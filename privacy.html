Dokument dotyczy osobistego programu Windows „Kalendarz Kariny” oraz tej strony informacyjnej. Osobą odpowiedzialną za osobistą konfigurację programu jest Karina Jaworek. Kontakt: wa.karinajaworek@gmail.com.

Jakie dane są odczytywane

Po skonfigurowaniu program odczytuje nagłówki, treści wiadomości i załączniki kalendarzowe .ics ze skrzynki IMAP, aby rozpoznać własne spotkania i terminy odpowiedzi. Nie analizuje treści załączników PDF ani Excel. Odczytuje istniejące wydarzenia oraz informacje o głównym kalendarzu konta Google, aby sprawdzić konto i ograniczać duplikaty.

Cel i uprawnienia Google

Dane służą wyłącznie organizacji osobistego kalendarza i prowadzeniu listy spraw do uzupełnienia. Program korzysta z uprawnień https://www.googleapis.com/auth/calendar.events do odczytu i zapisu wydarzeń oraz https://www.googleapis.com/auth/calendar.calendarlist.readonly do sprawdzenia konta kalendarza. Mimo że zakres Google może obejmować więcej kalendarzy dostępnych kontu, program kieruje zapisy do kalendarza głównego.

Przetwarzanie i odbiorcy

Analiza treści odbywa się lokalnie przez Ollama pod adresem 127.0.0.1. Kod programu nie przesyła treści do zewnętrznej usługi AI. Poczta jest pobierana od dostawcy IMAP, a do Google trafiają tworzone lub aktualizowane wydarzenia: ich tytuły, daty, opisy, przypomnienia i odnośniki do źródeł. Fragmenty pochodzące z poczty mogą znaleźć się w opisie wydarzenia. Ich widoczność zależy również od ustawień udostępniania kalendarza Google.

Program nie wysyła odpowiedzi ani zaproszeń. Dane Google nie są sprzedawane, używane do reklam ani do trenowania ogólnych modeli AI. Wykorzystanie danych uzyskanych z API Google jest ograniczone do opisanych funkcji i podlega Google API Services User Data Policy, w tym wymaganiom Limited Use.

Przechowywanie

Hasło IMAP i token OAuth zapisuje Menedżer poświadczeń Windows. Plik JSON klienta OAuth pozostaje w lokalizacji wybranej przez użytkowniczkę. Stan synchronizacji, dane zaproszeń .ics, wpisy programu, lista niejasnych spraw i dziennik działania są przechowywane lokalnie w folderze %LOCALAPPDATA%\KarinaCalendarSync. Folder ten może zawierać prywatne szczegóły i pozostaje do czasu jego usunięcia. Wydarzenia pozostają w Google Calendar do czasu ich zmiany lub usunięcia.

Wyłączenie i usunięcie danych

Można wyłączyć autostart programu, cofnąć jego dostęp w ustawieniach połączeń konta Google, usunąć jego poświadczenia w Windows i lokalny folder danych. Cofnięcie dostępu lub usunięcie lokalnych plików nie usuwa automatycznie wcześniejszych wydarzeń w Google Calendar; należy usunąć je osobno, jeśli są niepotrzebne.

Ta strona informacyjna

Strona nie zawiera formularza logowania, analityki ani kodu synchronizacji. Nie pobiera poczty i nie łączy się z kalendarzem. Po publikacji na GitHub Pages jej hosting obsługuje GitHub; dane techniczne odwiedzin, takie jak adres IP, mogą być przetwarzane zgodnie z polityką prywatności GitHub.
